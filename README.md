# Nos sites Biométhane — site public

Version « affichage seul » des cartes Biométhane, publiée avec GitHub Pages.

- `loire-ocean/` : carte de l'AI Loire Océan (Loire-Atlantique, Vendée, ouest du Maine-et-Loire).
- `pays-de-la-loire/` : carte des 5 départements des Pays de la Loire.

Chaque page relit le registre public ODRÉ à chaque ouverture : les nouveaux sites apparaissent tout seuls,
sans rien republier. Les pages ne contiennent ni outils de gestion ni adresses mail.

Pour changer la mise en page, refaire les pages depuis le projet (`Outils/construire.py --variante … --affichage`)
puis remplacer les fichiers `index.html` ici.
